Supabase Auth Execution

Below is the standard integration snippet being run behind this mockup to authenticate with Supabase:

// 1. Initialize Supabase / تهيئة مكتبة Supabase
import { createClient } from '@supabase/supabase-js';
const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

// 2. Attempt Authentication / محاولة التحقق وتسجيل الدخول
const { data, error } = await supabase.auth.signInWithPassword({
  email: emailInput.value,
  password: passwordInput.value
});

// 3. Handle Result & Metadata Redirection / معالجة النتيجة والتوجيه حسب الدور
if (error) {
  console.error(error.message);
} else {
  // Read user custom role from Supabase metadata
  const role = data.user.user_metadata.role || 'doctor';
  window.location.href = `/${role}/dashboard`;
}
